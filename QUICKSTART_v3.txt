📡 API ENDPOINTS (for testing)
═══════════════════════════════════════════════════════════════════════════

Jobs:
  GET /api/jobs/all - Get all jobs
  POST /api/jobs/create - Post job

Feed:
  GET /api/feed/all - Get all posts
  POST /api/feed/create - Create post
  POST /api/feed/:id/like - Like post

Profiles:
  GET /api/profiles/:user_id - Get profile
  POST /api/profiles/:user_id/picture - Upload picture

Payment:
  GET /api/payment/recruiter/:id - Check subscription
  POST /api/payment/hire - Record hire
  POST /api/payment/subscribe - Subscribe

Notifications:
  GET /api/notifications/:user_id - Get notifications
  POST /api/notifications/generate-matches - Get job matches

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ "Port 5002 not working"
   → Make sure npm start is running
   → Check if port changed (look at terminal)
   → Try: http://localhost:5001 or :5000

❌ "Signup not working"
   → Fill all fields (Name, Email, Phone, Password)
   → Try different email
   → Check browser console for errors

❌ "Dashboard not loading"
   → Clear browser cache (Ctrl+Shift+Del)
   → Hard refresh (Ctrl+F5)
   → Check if logged in (localStorage)

❌ "Can't see posts"
   → Create a post first
   → Refresh page
   → Check feed loading

❌ "Can't upload picture"
   → Feature coming soon (backend ready)
   → Use default avatar for now
