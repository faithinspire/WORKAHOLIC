================================================================================
        ✅ HOW TO SET ENVIRONMENT VARIABLES IN VERCEL
================================================================================

ERROR RECEIVED:
  "Environment Variable 'REACT_APP_API_URL' references Secret 
   'react_app_api_url', which does not exist."

CAUSE:
  The vercel.json was trying to reference environment variable secrets
  that weren't created yet.

✅ SOLUTION:
  Remove the env section from vercel.json (DONE)
  Set environment variables directly in Vercel UI (DO THIS NOW)

================================================================================
                    STEP-BY-STEP INSTRUCTIONS
================================================================================

1. Go to Your Vercel Project
   ➜ Visit https://vercel.com/dashboard
   ➜ Select your "faithjobs" or "WORKAHOLIC" project

2. Open Project Settings
   ➜ Click the "Settings" tab (top navigation)
   ➜ Left sidebar → "Environment Variables"

3. Add Environment Variables
   Add these 3 variables:

   VARIABLE 1:
   ├─ Name: REACT_APP_API_URL
   ├─ Value: http://localhost:5000
   │  (or your production backend URL)
   ├─ Environments: 
   │  ☑ Production
   │  ☑ Preview
   │  ☑ Development
   └─ Click "Save"

   VARIABLE 2:
   ├─ Name: SUPABASE_URL
   ├─ Value: https://zzpxjmmtlophkllboncl.supabase.co
   ├─ Environments: 
   │  ☑ Production
   │  ☑ Preview
   │  ☑ Development
   └─ Click "Save"

   VARIABLE 3:
   ├─ Name: SUPABASE_ANON_KEY
   ├─ Value: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   │  (from your Supabase project settings)
   ├─ Environments: 
   │  ☑ Production
   │  ☑ Preview
   │  ☑ Development
   └─ Click "Save"

4. Trigger New Deployment
   ➜ Go to "Deployments" tab
   ➜ Find your latest deployment
   ➜ Click the 3-dot menu (⋮)
   ➜ Select "Redeploy"
   ➜ Wait for new build (2-3 minutes)

5. Verify Deployment
   ✅ Build should complete successfully
   ✅ No more environment variable errors
   ✅ Site is live!

================================================================================
                    HOW TO GET SUPABASE VALUES
================================================================================

For SUPABASE_URL:
  1. Go to https://supabase.com
  2. Log in to your project
  3. Click "Settings" (bottom left)
  4. Copy your Project URL
  5. Paste in Vercel as SUPABASE_URL

For SUPABASE_ANON_KEY:
  1. Go to https://supabase.com
  2. Log in to your project
  3. Click "Settings" (bottom left)
  4. Go to "API" section
  5. Copy the "anon" (public) key
  6. Paste in Vercel as SUPABASE_ANON_KEY

For REACT_APP_API_URL:
  - Development: http://localhost:5000
  - Production: https://your-backend-url.com
  (Replace with your actual backend URL)

================================================================================
                    ENVIRONMENT VARIABLES EXPLAINED
================================================================================

REACT_APP_API_URL
  ├─ Purpose: Backend API base URL
  ├─ Used for: API calls to your Node.js server
  ├─ Example: http://localhost:5000
  └─ In Code: axios.post(`${process.env.REACT_APP_API_URL}/api/...`)

SUPABASE_URL
  ├─ Purpose: Supabase database connection
  ├─ Used for: Database queries and authentication
  ├─ Example: https://zzpxjmmtlophkllboncl.supabase.co
  └─ In Code: supabase.from('table_name').select()

SUPABASE_ANON_KEY
  ├─ Purpose: Public authentication key
  ├─ Used for: Client-side Supabase operations
  ├─ Example: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
  └─ In Code: supabase client initialization

================================================================================
                    IMPORTANT NOTES
================================================================================

✅ REACT_APP_API_URL Must Start With REACT_APP_
   Vercel only exposes variables that start with REACT_APP_ to the
   browser. Other variables are for server-side only.

✅ Keep Secrets Private
   Never commit Supabase keys to GitHub.
   Only set them in Vercel's UI.

✅ Test Each Environment
   Check that variables are available for:
   ✅ Production (live site)
   ✅ Preview (pull request deployments)
   ✅ Development (local)

✅ Redeploy After Changes
   Environment variable changes require a new deployment.
   Vercel won't automatically update without redeployment.

================================================================================
                    TROUBLESHOOTING
================================================================================

If Variables Not Working:

1. "REACT_APP_API_URL is undefined"
   ✓ Check variable name starts with REACT_APP_
   ✓ Verify all 3 variables are set
   ✓ Redeploy after setting variables
   ✓ Wait 30 seconds for cache to clear

2. "Cannot reach API"
   ✓ Check REACT_APP_API_URL is correct
   ✓ Verify backend server is running
   ✓ Check firewall/CORS settings
   ✓ Test with simple curl request

3. "Supabase connection failed"
   ✓ Check SUPABASE_URL is correct
   ✓ Check SUPABASE_ANON_KEY is correct
   ✓ Verify Supabase project is active
   ✓ Check database tables exist

4. "Environment variables not updating"
   ✓ Click "Redeploy" in Vercel dashboard
   ✓ Wait for new build (2-3 minutes)
   ✓ Hard refresh browser (Ctrl+Shift+R)
   ✓ Clear browser cache
