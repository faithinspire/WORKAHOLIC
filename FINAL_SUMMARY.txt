TROUBLESHOOTING
================================================================================

Problem: News not showing
  → Clear cache (Ctrl+Shift+Delete)
  → Refresh page (F5)
  → Restart server (npm start)

Problem: Can't access localhost:5002
  → Make sure npm start is running
  → Wait 5 seconds for startup
  → Check port (look at terminal)
  → Try: http://localhost:5001 or :5000

Problem: Signup/Login not working
  → Make sure all fields are filled
  → Try different email
  → Check browser console (F12)
  → Restart server

Problem: Old page showing
  → Clear browser cache completely
  → Hard refresh: Ctrl+F5
  → Try incognito mode

For more help:
  → See FRESH_START_INSTRUCTIONS.txt section "Troubleshooting"
