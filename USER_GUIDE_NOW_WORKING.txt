API ENDPOINTS (FOR DEVELOPERS)
═════════════════════════════════════════════════════════════════

Signup:
POST /api/auth/signup
Request: {email, password, fullname, phone, role}
Response: {token, user}

Login:
POST /api/auth/login
Request: {email, password}
Response: {token, user}

Admin Login:
POST /api/admin/login
Request: {email, password}
Response: {token, user}

News:
GET /api/news/all
Response: {news[], total, source, databaseStatus}
