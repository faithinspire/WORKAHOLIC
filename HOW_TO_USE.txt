================================================================================
                         TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: "Cannot connect to server"
SOLUTION: 
- Make sure server is running (Step 1)
- Check if port 5001 is being used
- Try http://localhost:5000 (if 5001 is taken)


PROBLEM: "Signup button doesn't work"
SOLUTION:
- Check browser console (F12 key)
- Make sure all fields are filled
- Try different email address
- Clear browser cache


PROBLEM: "Dashboard doesn't show after signup"
SOLUTION:
- Wait a few seconds
- Refresh page (F5)
- Check localStorage in browser (F12 → Application)
- Try another browser


PROBLEM: "Admin login fails"
SOLUTION:
- Use exact credentials (copy-paste if needed)
- Email: admin@workaholic.com
- Password: Admin123456
- Clear browser cookies
- Try incognito mode


PROBLEM: "Jobs section shows no jobs"
SOLUTION:
- This is normal - sample data loaded
- They're displayed from sample data
- In production, jobs will be from database


PROBLEM: "Feeds not showing after creation"
SOLUTION:
- Refresh the page
- Try creating different content
- Check browser console for errors
- Ensure you're logged in

================================================================================
                          KEEPING IT RUNNING
================================================================================

To Keep Server Running:
- Don't close the terminal/CMD window
- Server will keep running until window closes
- To stop: Press Ctrl+C in terminal

To Restart:
- Close the terminal
- Open new terminal
- Navigate to project folder
- Run: node server.js

To Run in Background (Advanced):
- Use npm script in package.json
- Or use process manager like PM2
- See documentation for details
