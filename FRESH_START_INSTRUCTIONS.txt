================================================================================
TROUBLESHOOTING
================================================================================

❌ PROBLEM: News articles not showing
   SOLUTION: 
   1. Clear browser cache (Ctrl+Shift+Delete)
   2. Refresh page (F5)
   3. Check server is running on http://localhost:5002/api/health
   4. If still not working, restart server (npm start)

❌ PROBLEM: Signup button not working
   SOLUTION:
   1. Check all form fields are filled
   2. Try different email address
   3. Open browser console (F12) and check for errors
   4. Restart server and try again

❌ PROBLEM: Login says "Invalid credentials"
   SOLUTION:
   1. Verify account exists - try signup first
   2. Check email and password are exact match
   3. Try admin account to test: admin@workaholic.com / Admin123456
   4. Clear browser cache and try again

❌ PROBLEM: Can't access http://localhost:5002
   SOLUTION:
   1. Make sure server is running (npm start in terminal)
   2. Wait 5 seconds for server to start
   3. Check if port changed (look at terminal output)
   4. If shows "port 5001" use http://localhost:5001 instead
   5. Restart your terminal and try npm start again
