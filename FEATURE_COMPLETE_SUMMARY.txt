                        HOW TO USE (QUICK START)
================================================================================

1. SERVER RUNNING
   - Should already be running on port 5001
   - If not: node server.js

2. OPEN BROWSER
   - Go to http://localhost:5001

3. LOGIN
   - Create new account or login existing
   - You'll land on HOME page

4. UPLOAD PROFILE PHOTO (Optional)
   - Click Profile
   - Click camera icon

   - Comment (click 💬)
   - See comments appear
   - Read all comments

7. EXPLORE
   - Try all features
   - Test on mobile
   - Create multiple posts
   - Comment and like
