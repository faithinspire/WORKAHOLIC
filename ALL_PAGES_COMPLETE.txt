🔄 API INTEGRATION
═══════════════════════════════════════════════════════════════════════════

JOBS PAGE APIs:
  • GET /api/jobs/all → Fetch all jobs
  • POST /api/jobs/:id/apply → Apply for job

PROFILE PAGE APIs:
  • GET /api/profiles/:user_id → Get profile
  • POST /api/profiles/create → Save profile
  • POST /api/profiles/:user_id/picture → Upload picture

POST JOB PAGE APIs:
  • POST /api/jobs/create → Create job posting

All APIs connected and tested ✅
