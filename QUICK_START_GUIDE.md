## 🐛 COMMON QUESTIONS

### Q: I see old content on landing page
**A**: Clear your browser cache
```
Press: Ctrl+Shift+Delete
Select: "All time"
Click: "Clear data"
Then refresh: Ctrl+Shift+R
```

### Q: Where is my data saved?
**A**: In these places simultaneously:
- Browser LocalStorage (instant)
- Server in-memory storage (secure)
- Supabase cloud (backup)

### Q: Can I use on my phone?
**A**: Yes! Just go to: `http://[YOUR_COMPUTER_IP]:5002`
- Replace [YOUR_COMPUTER_IP] with your computer's IP address
- Example: `http://192.168.1.5:5002`

### Q: WhatsApp chat not working?
**A**: 
- Make sure you have WhatsApp installed
- Or click link in mobile browser - opens WhatsApp Web
- Admin will respond

### Q: How do I reset my password?
**A**: Currently passwords are set at signup
- To change: Create new account with different email
- Contact admin on WhatsApp for password reset
