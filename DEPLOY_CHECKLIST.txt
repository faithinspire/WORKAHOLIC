===============================================
TROUBLESHOOTING
===============================================

If build fails:
1. Check Vercel build logs for specific error
2. Common issues:
   - Missing environment variables (set in Vercel UI)
   - Node version mismatch (Vercel uses Node 18.x by default)
   - Missing dependencies (should auto-install)

If page loads but no styling:
1. Check browser console for CSS errors
2. Verify API endpoint in REACT_APP_API_URL
3. Clear browser cache and reload

If API calls failing:
1. Verify REACT_APP_API_URL is correct and accessible
2. Check CORS headers on backend
3. Verify Supabase credentials
