PROFILE PHOTO UPLOAD
====================

In Profile section:

1. Look for camera icon 📷 on your avatar
2. Click it
3. Select photo from device
4. Wait for upload
5. Photo updates immediately
6. Used in all posts and comments

Photo Requirements:
- Format: JPG, PNG, GIF
- Size: Recommended 1MB or less
- Dimensions: Any size (will be cropped to circle)


CREATING A POST WITH PHOTO
===========================

Step by step:

1. On Home page, find post creation box
2. Type your message
   Example: "Successfully completed my Advanced Math class!"

3. Click "Add Photo" button
4. Select image from computer
5. See preview of image below text box
6. Can remove with × button if needed
7. (Optional) Click "Add Feeling" to add emoji

8. Click "POST" button
9. Watch post appear at top of feed
10. Other users can now see it!

Post will include:
- Your name
- Your profile photo
- Your message text
- Your uploaded photo (if added)
- Like count
- Comment count
- Timestamp


ADDING COMMENTS (MOBILE-FRIENDLY)
=================================

To comment on any post:

1. Find post you want to comment on
2. Click 💬 "Comment" button
3. Comment text box appears
4. Type your comment
   Example: "This is amazing! Keep up the great work! 👏"
5. Click "Post" button
6. Your comment appears in comments section
7. Shows your name and time posted
8. Click "Cancel" if you change mind

Comment Features:
✅ See all comments on post
✅ Responsive on mobile (full width)
✅ See commenter name
✅ See comment timestamp
✅ Beautiful card layout
✅ Multiple comments displayed
✅ Comment count shows total


LIKING POSTS
============

Simple and intuitive:

1. Find post you like
2. Click ❤️ "Like" button
3. Heart turns RED (liked)
4. Like counter increases by 1
5. Click again to unlike
6. Heart turns GRAY
7. Like counter decreases
8. No limit to likes!

================================================================================
                        TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: Photo not showing after upload
SOLUTION:
- Wait a moment, it may be processing
- Refresh page (F5)
- Try smaller file size
- Try JPG format instead of PNG

PROBLEM: Comment not appearing
SOLUTION:
- Check text is not empty
- Click "Post" again
- Refresh page
- Try different browser

PROBLEM: Like button not working
SOLUTION:
- Make sure you're logged in
- Refresh page
- Clear browser cache
- Try different browser

PROBLEM: Photos too large
SOLUTION:
- Compress before uploading
- Use online image compressor
- Keep under 5MB
- Use common formats (JPG, PNG)

PROBLEM: Mobile display looks weird
SOLUTION:
- Reload page (F5)
- Rotate phone
- Try different browser
- Check internet connection

PROBLEM: Can't see other people's photos
SOLUTION:
- Make sure posts have photos
- Scroll down to load more posts
- Check for error messages
- Refresh page

================================================================================
                         DATA & PERSISTENCE
================================================================================

Where is my data stored?
- All posts saved in browser (localStorage)
- Profile photos saved in browser
- Comments saved with posts
- Likes tracked per user
- Data persists when you close browser

Access in DevTools:
- F12 → Application → Local Storage
- Look for "allFeeds" key
- See all posts data

Clear Data:
- F12 → Application → Local Storage
- Delete "allFeeds" key
- Clears all posts (careful!)
