================================================================================
                    TROUBLESHOOTING QUICK TIPS
================================================================================

Problem: Still seeing old JavaScript code at bottom of page
Solution: Clear browser cache (Ctrl+Shift+Delete) and hard refresh

Problem: Data not saving
Solution: Check browser console (F12) for errors. Data saves to 3 places:
  1. Browser localStorage
  2. Server memory
  3. Supabase cloud

Problem: Comments not showing
Solution: 
  1. Make sure you're on the Community Feed page
  2. Type in the comment box and click "Post"
  3. Refresh the page to see updates

Problem: Mobile view not showing bottom navbar
Solution:
  1. Resize browser to less than 768px width
  2. OR visit from actual phone
  3. Navbar should appear at bottom

Problem: WhatsApp button not opening
Solution:
  1. Make sure WhatsApp is installed on phone OR
  2. Using WhatsApp Web (web.whatsapp.com)
  3. Try clicking the green bubble again
