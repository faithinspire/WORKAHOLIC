                        KEY ENDPOINTS
================================================================================

COMMENTS:
  POST   /api/feed/:id/comment              Add comment
  GET    /api/feed/:id/comments             Get comments
  DELETE /api/feed/:postId/comment/:commentId Delete

NEWS:
  GET    /api/external-news/all             Get news (30-min)
  POST   /api/external-news/refresh         Refresh now
  GET    /api/external-news/status          Check status

DASHBOARD:
  GET    /api/dashboard/:userId             Get dashboard
  GET    /api/dashboard/notifications/:userId Get notifications
  GET    /api/dashboard/portfolio/:userId   Get portfolio

JOB REQUESTS:
  POST   /api/dashboard/job-requests/send   Send interest
  GET    /api/dashboard/job-requests/recruiter/:id Get requests
  POST   /api/dashboard/job-requests/:id/respond  Respond
