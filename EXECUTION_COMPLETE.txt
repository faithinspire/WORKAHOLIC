🆘 TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

Problem: News not showing
  Solution: Clear cache (Ctrl+Shift+Delete) → Refresh (F5) → Restart server

Problem: Can't access localhost:5002
  Solution: Check npm start is running → Wait 5 sec → Check terminal for port

Problem: Signup/Login not working
  Solution: Fill all fields → Use different email → Check console (F12)

Problem: Old page showing
  Solution: Hard refresh (Ctrl+F5) → Clear cache → Try incognito

For more: See FRESH_START_INSTRUCTIONS.txt "Troubleshooting" section
