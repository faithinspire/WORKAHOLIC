================================================================================
                         DATA STRUCTURE
================================================================================

USER PROFILE:
  - user_id (unique identifier)
  - user_name (display name)
  - bio (profile bio)
  - job_category (teaching, tech, freelance, etc.)
  - location (city/state)
  - phone (contact)
  - profile_picture (URL to image)
  - followers (array of follower objects)
  - following (array of following objects)
  - total_followers (count)
  - total_posts (count)
  - total_jobs_posted (count)
  - created_at (timestamp)
  - updated_at (timestamp)

FEED POST:
  - id (post_* format)
  - user_id (author)
  - user_name (author name)
  - user_picture (author avatar)
  - text (post content)
  - image (optional image)
  - emoji (emoji on post)
  - likes (like count)
  - liked_by (array of likers)
  - comments (array of comments)
  - reactions (emoji reaction counts)
  - created_at (timestamp)

COMMENT:
  - id (comment_* format)
  - user_id (commenter)
  - user_name (commenter name)
  - user_picture (commenter avatar)
  - text (comment content)
  - emoji (comment emoji)
  - likes (like count)
  - liked_by (array of likers)
  - timestamp (creation time)

                         SUPPORT
================================================================================

ISSUE: Data not appearing after refresh
SOLUTION:
1. Data persists for current session
2. For permanent persistence, use Supabase database
3. Clear browser cache (Ctrl+Shift+Delete)
4. Hard refresh (Ctrl+Shift+R)

ISSUE: Server won't start on port 5002
SOLUTION:
1. Kill existing process on that port
2. Or server will auto-upgrade to 5003, 5004, etc.
3. Check running ports: netstat -ano

ISSUE: Pictures not uploading
SOLUTION:
1. Verify image < 5MB
2. Use JPG or PNG format
3. Check internet connection
4. Try again after refresh
