## 🚀 Quick Demo Script

### Step 1: Open the Application
```
1. Open browser
2. Go to: http://localhost:5000
3. You should see beautiful landing page with:
   - Professional teacher image in hero
   - "Featured Teachers" section
   - "Community Feeds" section
   - "Available Jobs" section
```

### Step 2: Create Teacher Account
```
1. Click "Create Account" button
2. Select "Teacher" role
3. Fill form:
   - Full Name: "John Doe"
   - Email: "john@example.com"
   - Password: "Test123456"
   - Phone: "08012345678"
   - Subject: "Mathematics"
   - Experience: "5"
   - State: "Lagos"
4. Click "Create Account"
5. ✨ Dashboard appears with profile info
```

### Step 3: Create Recruiter Account
```
1. Logout (click profile → Logout)
2. Click "Create Account"
3. Select "Recruiter" role
4. Fill form:
   - Full Name: "Jane School"
   - Email: "recruiter@example.com"
   - Password: "Test123456"
   - Company Name: "Excellence Academy"
   - Institution Type: "School"
   - State: "Lagos"
5. Click "Create Account"
6. ✨ Recruiter dashboard appears
```

### Step 4: Test Features
```
1. View Featured Teachers
   - 5 sample teachers displayed with photos, ratings
   - Search by name/subject
   
2. View Jobs
   - Sample jobs displayed with salary info
   - Job type (School/Online/Private)
   
3. View Notifications
   - Job alerts auto-trigger after login
   - Sample notification shows new opportunities
   
4. Test Mobile
   - Resize browser to mobile size (375px)
   - Bottom navbar should appear
   - All content should reflow nicely
```

### Step 5: Payment Demo
```
1. As recruiter, click "Hire" on a teacher
2. Payment modal appears
3. First hire shows: "₦0 FREE"
4. Shows: "After first hire: ₦5,000/month subscription"
5. Click confirm
6. Teacher hired successfully!
```
