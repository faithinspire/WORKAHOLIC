================================================================================
                        TROUBLESHOOTING
================================================================================

Comments not working?
  1. Clear cache (Ctrl+Shift+Delete)
  2. Hard refresh (Ctrl+Shift+R)
  3. Make sure you're logged in
  4. Try on different browser

Admin not responsive?
  1. Resize browser to < 768px
  2. Should see bottom navigation
  3. If not, clear browser cache

News not updating?
  1. Check /api/news/status endpoint
  2. Shows next refresh time
  3. Will auto-update at scheduled time
  4. Manual refresh: POST /api/news/refresh

Connection issues?
  1. Check server is running: curl http://localhost:5001/api/health
  2. Server should respond with status
  3. Check server logs for errors
  4. Restart server if needed

================================================================================
                        RESTART SERVER (if needed)

   - Ctrl+C in terminal

   - Run: node server.js
   - Wait for: "✅ Server running on port 5001"

3. Clear browser cache and refresh:
   - Ctrl+Shift+Delete → Clear All
   - Ctrl+Shift+R → Hard refresh
   - Go to http://localhost:5001
